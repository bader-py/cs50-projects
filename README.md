# cs50-projects
## About the Course

This repository documents my journey through **CS50: Introduction to Computer Science**
from Harvard University — one of the world's most well-known courses in programming
fundamentals and computer science.

The course covered topics like algorithms, data structures, memory management,
security, and web development — across multiple languages, primarily C.

Through it, I developed skills in:
- Algorithmic thinking and systematic problem-solving
- Memory management and pointers in C
- Building and analyzing data structures (arrays, hash tables)
- Writing clean, debuggable code

This course was an important starting point for me, and it supported my journey
in the AI diploma program I'm currently studying — especially in understanding
the fundamentals that any model or algorithm is built on.
